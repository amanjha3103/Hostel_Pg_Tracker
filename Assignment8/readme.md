# Assignment 8 - Hostel/PG Room Availability Catalogue


## How to Run

From the `Hostel_Pg_Tracker` folder, run:

```bash
cd Assignment8
npm install
node server.js
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
